# CMS block contracts

The authoritative UID list contains 19 entries. Frontend compile-time coverage and the contract test prevent drift. Each block accepts optional shared settings: anchor ID, internal name, theme, top/bottom spacing, visibility, tracking ID, background media, and version.

Invalid optional blocks are logged with UID, ID, route, locale, and safe issue paths. Production skips them; development renders a small diagnostic. Critical page/article/site schemas produce structured server errors and safe page behavior.
